# FadeBreak:一款按 20-20-20 原则设计的 Android 护眼提醒

FadeBreak 是一个 Android 护眼提醒应用,灵感来自 Windows 的 [FadeTop](http://fadetop.com)。

**工作方式**:检测到连续亮屏使用达到设定时长(默认 20 分钟)后,在屏幕上缓缓淡入一张半透明图片,提示你离开屏幕休息。图片覆盖全屏,点击可关闭;停留满 20 秒视为一次有效休息,自动淡出并重新计时;若提前关闭,默认 60 秒后再次提醒。

## 设计依据:20-20-20 原则

美国眼科学会(AAO)推荐:每用眼 20 分钟,看向约 20 英尺(6 米)外,持续至少 20 秒,以缓解数字眼疲劳。

| 20-20-20 | FadeBreak |
|---|---|
| 每 20 分钟 | 休息间隔(默认 20 分钟) |
| 看向约 6 米外 | 全屏渐变图片 |
| 持续 20 秒 | 护眼时长(默认 20 秒) |

## 主要特性

- 到点渐变图片,不打断当前操作;达标自动结算
- 白名单:看视频 / 玩游戏时前台不提醒
- 背景自定义(纯色 / 图片 / 文件夹轮播),支持预览
- 静默常驻、无通知;保活自检按 ROM 给出指引
- 纯本地:无网络权限,无障碍服务不读取屏幕内容

## 说明

- 仅支持 Android 8.0+;iOS 不可用(iOS 不允许第三方 App 跨应用盖遮罩)
- 部分 ROM 会限制后台运行,需按提示配置自启动 / 电池白名单
